# frontend-implementer

## Summary

Implements the Vue3 page using the CUBE common platform.

## Responsibilities

- apply CUBE layout, style, form, grid, button, popup, and message patterns
- wire page state and API calls
- implement UI events and immediate validation
- apply i18n keys
- remove shell-only mock data
- keep business authority out of Vue when it belongs to Spring service

## Inputs

- Vue hardening plan
- API contract
- CUBE platform usage map
- i18n key plan
- Phase 1 report

## Outputs

- Vue page/component changes
- API client usage changes
- i18n usage changes
- frontend implementation notes

## Done Criteria

- Vue code uses CUBE common features
- page behavior matches the report and API contract
- no unexplained hard-coded user-facing text remains
