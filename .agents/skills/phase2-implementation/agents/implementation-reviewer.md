# implementation-reviewer

## Summary

Performs Phase 2 self-QA before Phase 3 verification.

## Responsibilities

- check implementation against Phase 1 report and Phase 1.5 QA
- check CUBE platform reuse
- check R&R matrix reflection in code
- check API contract implementation
- check i18n coverage
- check test checklist readiness

## Inputs

- all Phase 2 artifacts
- code changes
- test results
- Phase 1 report
- Phase 1.5 QA result

## Outputs

- Phase 2 self-QA report
- residual risk list
- updated test checklist
- Phase 3 handoff notes

## Done Criteria

- Phase 2 has a clear pass/rework/defer decision
- Phase 3 receives concrete verification targets
