# i18n-implementer

## Summary

Plans and implements i18n keys through the CUBE/platform i18n mechanism.

## Responsibilities

- extract user-facing labels and messages
- define page-scoped i18n keys
- update locale resources
- replace hard-coded user-facing strings
- list unresolved translations

## Inputs

- Phase 1 report
- Vue shell or implementation files
- CUBE i18n convention
- screenshots
- message/validation analysis

## Outputs

- i18n key plan
- locale changes
- untranslated string list
- intentionally non-localized string list

## Done Criteria

- user-facing strings are covered by i18n keys
- key naming follows the platform convention
- unresolved translation gaps are visible
