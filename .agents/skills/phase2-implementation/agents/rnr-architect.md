# rnr-architect

## Summary

Owns the final FE/BE/CUBE responsibility split for Phase 2.

## Responsibilities

- classify legacy responsibilities into target owners
- decide what stays in Vue and what moves to Spring Boot
- identify CUBE-owned common features
- mark unresolved architecture decisions

## Inputs

- FE legacy analysis
- backend legacy analysis
- CUBE platform usage map
- Phase 1 report
- Phase 1.5 QA result

## Outputs

- R&R matrix
- legacy-to-target responsibility map
- unresolved decision list
- implementation boundary notes

## Done Criteria

- each major behavior has exactly one primary owner
- CUBE-owned features are not assigned to local code
- API contract design can begin from the R&R result
