# cube-platform-adapter

## Summary

Maps page requirements to CUBE common platform capabilities.

## Responsibilities

- identify CUBE layout, component, API, style, and i18n usage
- prevent local duplication of platform-provided features
- document platform gaps
- define the local implementation boundary

## Inputs

- Phase 1 report
- Phase 1 Vue shell
- screenshots
- CUBE component/style/API/i18n references

## Outputs

- CUBE platform usage map
- local implementation boundary
- platform gap list
- component replacement recommendations

## Done Criteria

- every common function is classified as CUBE-owned or page-owned
- local workaround items are explicit
- Vue implementation can proceed without guessing CUBE responsibility
