# backend-implementer

## Summary

Implements or adapts Spring Boot API endpoints for the converted page.

## Responsibilities

- implement controller methods
- define request/response DTOs
- connect services and mappers
- implement authoritative validation and business rules
- apply common error response patterns
- preserve legacy traceability

## Inputs

- API contract
- backend trace map
- R&R matrix
- target Spring Boot conventions
- CUBE/common backend conventions

## Outputs

- controller/service/DTO/mapper changes
- backend implementation notes
- legacy API traceability notes
- backend test scenario notes

## Done Criteria

- implemented backend matches the API contract
- Vue payload and Spring DTO shape agree
- business validation does not rely only on FE code
