# 2단계 산출물 체크리스트

## Gate Checklist

- [ ] 1단계 보고서를 구현 source of truth로 사용했다.
- [ ] 1단계 CSV 산출물을 구현 입력으로 사용했다.
- [ ] 1단계 스크린샷과 Vue shell을 구현 기준으로 사용했다.
- [ ] 1.5단계 QA 지적 사항을 해결 또는 보류 처리했다.
- [ ] CUBE 플랫폼 사용 맵을 구현 전에 만들었다.
- [ ] CUBE 공통 컴포넌트 매핑을 실제 Vue component 치환에 반영했다.
- [ ] CUBE menu/route/page frame/action area를 실제 구현에 반영했다.
- [ ] CUBE style token/component variant를 실제 template/style에 반영했다.
- [ ] CUBE 공통 기능을 로컬로 중복 구현하지 않았다.
- [ ] FE/BE/CUBE R&R matrix를 만들었다.
- [ ] API/controller 계약을 deep Vue 구현 전에 설계했다.
- [ ] Vue shell placeholder를 CUBE 컴포넌트 또는 실제 구현으로 교체했다.
- [ ] API client payload가 Spring request DTO와 맞는다.
- [ ] Spring response DTO가 Vue grid/detail binding과 맞는다.
- [ ] 사용자 노출 문구가 i18n key를 사용한다.
- [ ] FE 단위 테스트 또는 대체 검증을 수행했다.
- [ ] BE 단위 테스트 또는 대체 검증을 수행했다.
- [ ] API 셀프 테스트를 수행했다.
- [ ] FE/BE 피드백 루프를 수행했다.
- [ ] legacy transaction/controller/service/mapper traceability를 남겼다.
- [ ] Phase 3 검증 항목과 재현 방법을 남겼다.
